Алгоритм

1. Загрузи HTML страницы по URL
2. Если обычный web_fetch блокируется robots.txt или антибот-защитой/капчей Ozon, пробуй открыть страницу в браузере и парсить через get_page_text/javascript_tool
3. Распарсить HTML
4. Найти цену (regular_price) — цена в блоке `webPrice`, подписанная "С другими банками" (в примере: `<span class="pdp_ib0 tsHeadline500Medium">17 131 ₽</span>`)
5. Найти скидку (sale_price) — крупная цена в том же блоке `webPrice`, подписанная "С банками" (в примере: `<span class="tsHeadline600Large">15 417 ₽</span>`)
6. Найти рассрочку (has_credit) <span class="tsBodyControl400Small" style="color: var(--textLightKey);">Оплатить позже</span>
7. Не путать regular_price/sale_price с ценой из блока `webBestSeller` ("Есть дешевле" — цена стороннего продавца), этот блок игнорировать
8. CSS-классы Ozon — сгенерированные хэши, которые регулярно меняются; ориентируйся на структуру (виджет `webPrice`, подписи "С банками"/"С другими банками"), а не на точные имена классов
9. Убрать пробелы в числе, символ ₽ оставить как есть (например: "17 131 ₽" → "17131₽")
10. Перевести текстовые значения "Оплатить позже" в true, если есть, иначе false
11. Если цена (regular_price) не найдена, вернуть null
12. Если цена со скидкой (sale_price) не найдена, вернуть null
